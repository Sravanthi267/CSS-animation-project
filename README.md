# CSS Animation Project

This project demonstrates basic CSS animations using HTML and CSS.

## 🚀 Features
- Smooth animation using @keyframes
- Translate and Rotate effects
- Infinite animation loop
- Color transition effects

## 🛠 Technologies Used
- HTML5
- CSS3

## 📌 Project Description
This animation project was created as part of my college training to practice CSS animation concepts and improve frontend development skills.
